# TeamWorkEvidence

Vue 3 + TypeScript + Vite 5

## Mobile team builder

Ветка `dev-mobile` содержит мобильный сценарий подбора команды, доступный по маршруту `/teams`.

- поиск специалистов по роли, навыку, доступности, формату работы и рейтингу;
- карточки профилей и подробный просмотр специалиста;
- добавление участников в черновик, назначение роли и рабочие заметки;
- показатель готовности команды и список незакрытых ключевых ролей;
- сохранение черновика в `localStorage`;
- адаптивный интерфейс с нижней навигацией для мобильных устройств.

Данные специалистов пока работают через локальный сервис. Его можно заменить реальным API без изменений в компонентах: точка интеграции находится в `src/services/teamBuilderService.ts`.

## Scripts

| Команда             | Описание                            |
| ------------------- | ----------------------------------- |
| `pnpm dev`          | Запуск dev-сервера                  |
| `pnpm build`        | Type-check + production-сборка      |
| `pnpm preview`      | Предпросмотр production-сборки      |
| `pnpm test`         | Запуск тестов (Vitest, один прогон) |
| `pnpm test:watch`   | Тесты в watch-режиме                |
| `pnpm lint`         | ESLint по `src/`                    |
| `pnpm format`       | Prettier — форматирование           |
| `pnpm format:check` | Prettier — проверка форматирования  |
